When you want a real link

Want families to open it online?

If Codex makes something worth sharing - a class webpage, a family resource page, or a tiny classroom tool - it can help put that online too. The free place for that is called GitHub. Think: a parking spot for the website so it has an actual link.

You do not have to know web design, HTML, CSS, or GitHub first. Codex can make the page, style it, add pictures, make it work on phones, and then work smoothly with GitHub when it is time to share it. The tech word is "push." In normal human: upload the finished version so people can open it.
